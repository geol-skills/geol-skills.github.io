Week 6: Live code

The null world, the t-test, and its assumptions

The live coding from Week 6: Testing hypotheses, to reproduce at home. Stainmore boreholes read warmer than Whin Sill ones: could chance alone produce a gap that big? Then: what does a t-test assume, and what happens when the assumption fails?

borehole_temp.csv has one row per borehole: its formation and its temperature_c.

1. Build the null world

Slide

  • set.seed(n) (new): fixes R’s random numbers, so a shuffle comes out the same every time you run it. Any whole number will do; 2341 matches the lecture.
  • replicate(n, { … }): met in Week 5. Curly brackets let it repeat several lines; the last line’s value is what it collects.
  • Already met: read.csv(), mean(), [ ], ==, sample() (Week 5).
NoteHint 1
  1. Read the file into borehole. temp <- borehole$temperature_c saves typing.
  2. The mean of temp where formation is "Stainmore", minus the mean where it is "Whin Sill".
  3. sample() the formation labels, then repeat step 2 with the shuffled labels. Run it a few times: each shuffle gives a different delta.
  4. set.seed(2341), then wrap step 3 in replicate(1000, { … }).
NoteHint 2

shuffled <- sample(<labels>)
mean(temp[<shuffled is Stainmore>]) - mean(temp[<shuffled is Whin Sill>])

set.seed(2341)
null_deltas <- replicate(1000, {
  <the two lines above>
})

TipSolution

  mean(temp[borehole$formation == "Whin Sill"])
delta

  shuffled <- sample(borehole$formation)

})

δ = 8.417 °C. Each single shuffle gives a δ near zero. Put the seed immediately before replicate(), as here, to match the lecture’s numbers; anywhere else and they move a little. A simulated p-value is an estimate.

2. Interrogate the null world

Slide

  • geom_vline(xintercept = …) (new): draws vertical lines across a plot at the x values you give it.
  • abs(x): the size of a number, ignoring its sign.
  • mean() of TRUE/FALSE values: TRUE counts as 1 and FALSE as 0, so the mean is the fraction that are TRUE.
  • Already met: ggplot(), aes(), geom_histogram(), data.frame(), sd().
NoteHint 1
  1. ggplot() needs a data frame: data.frame(null_deltas) makes one. Mark delta and -delta: “this extreme” counts either way.
  2. Is each shuffled δ at least as far from zero as ours? That gives 1000 TRUE/FALSE values; their mean is the fraction.
  3. sd() of the null world.
NoteHint 2 
ggplot(data.frame(null_deltas), aes(x = null_deltas)) +
  geom_histogram(bins = 30) +
  geom_vline(xintercept = <both deltas>, colour = "red")

mean(<size of null_deltas> >= <size of delta>)
sd(<null world>)
NoteHint 3 
ggplot(data.frame(null_deltas), aes(x = null_deltas)) +
  geom_histogram(bins = 30) +
  geom_vline(xintercept = c(-delta, ______), colour = "red")

mean(______(null_deltas) >= ______(delta))
sd(______)
TipSolution 
ggplot(data.frame(null_deltas), aes(x = null_deltas)) +
  geom_histogram(bins = 30) +
  geom_vline(xintercept = c(-delta, delta), colour = "red")

mean(abs(null_deltas) >= abs(delta))

sd(null_deltas)

p = 0.022: 22 of 1000 shuffles are as extreme as ours. The null deltas run from about −12.4 to +11.4 °C. Their standard deviation, about 3.8 °C, is the standard error of δ: how far δ wanders between samples when nothing is going on.

3. The t-test

Slide

  • t.test(outcome ~ group, data = …) (new): takes a numeric column and a column of two group labels, and returns the t-statistic, its degrees of freedom, the p-value and a 95 % confidence interval for the difference in means.
  • ~ (new): read it as “explained by”. temperature_c ~ formation is “temperature, split by formation”.
  • Already met: ggplot(), aes(), geom_point(), geom_violin() (Week 5).
NoteHint 1

Look first: temperature for each formation, as points. Then hand t.test() the outcome, the groups, and the data frame.

NoteHint 2 
ggplot(borehole, aes(x = formation, y = temperature_c)) +
  geom_point()

t.test(______ ~ ______, data = borehole)
TipSolution 
ggplot(borehole, aes(x = formation, y = temperature_c)) +
  geom_point()

t.test(temperature_c ~ formation, data = borehole)

t = 2.24, df = 47.2, p = 0.030; 95 % CI 0.9 to 16.0 °C. The shuffle gave 0.022: same question, same answer, two routes. “The mean difference is 8.4 °C (95 % CI 0.9 to 16.0 °C); if the formations really didn’t differ, a gap this big would turn up about 3 % of the time.”

4. Independence

Slide

  • rnorm(n, mean, sd) (new): makes n random numbers from a normal distribution with that mean and standard deviation.
  • rep(x, each = n): repeats each value of x n times.
  • core_mean[core]: picks one value of core_mean for each plug, by its core number.
  • geom_jitter(width = …) (new): geom_point(), with each point nudged sideways at random so piles of points don’t hide each other.
  • aggregate(y ~ a + b, data = …, FUN = mean) (new): tapply()’s cousin that keeps the labels. It gives a data frame with the mean of y for every combination of a and b.
  • Already met: set.seed(), data.frame(), t.test(), factor(), ggplot(), aes().
NoteHint 1
  1. Number the 8 cores 1 to 8, ten plugs each; cores 1–4 come from quarry A, 5–8 from quarry B. Give each core its own mean porosity (around 15 %, varying by 3), then each plug its core’s mean plus a little noise. set.seed(20) first, to match the lecture.
  2. t.test() porosity by quarry, on all 80 plugs.
  3. There is no test for independence: plot the plugs, coloured by core.
  4. aggregate() the plugs to one mean per core, and test again.
NoteHint 2 
set.seed(20)
core <- rep(1:8, each = <plugs per core>)
quarry <- rep(c("A", "B"), each = <plugs per quarry>)
core_mean <- rnorm(<cores>, mean = 15, sd = 3)
plugs <- data.frame(quarry, core,
                    porosity = core_mean[core] + rnorm(<plugs>, sd = 1))

t.test(<porosity by quarry>, data = plugs)
ggplot(plugs, aes(x = quarry, y = porosity, colour = factor(core))) +
  geom_jitter(width = 0.15)
cores <- aggregate(<porosity by core and quarry>, data = plugs, FUN = mean)
t.test(<porosity by quarry>, data = cores)

TipSolution 
set.seed(20)
core <- rep(1:8, each = 10)
quarry <- rep(c("A", "B"), each = 40)
core_mean <- rnorm(8, mean = 15, sd = 3)
plugs <- data.frame(quarry, core,
                    porosity = core_mean[core] + rnorm(80, sd = 1))

t.test(porosity ~ quarry, data = plugs)

ggplot(plugs, aes(x = quarry, y = porosity, colour = factor(core))) +
  geom_jitter(width = 0.15)

cores <- aggregate(porosity ~ core + quarry, data = plugs, FUN = mean)
cores
t.test(porosity ~ quarry, data = cores)

All 80 plugs: p = 0.0004. Quarry A is 3.3 percentage points more porous (95 % CI 1.5 to 5.0), though we built in no difference. The plot shows eight tight clumps: ten plugs from one core repeat one piece of information ten times. One mean per core: the same 3.3 point gap, but p = 0.33 (df = 6), 95 % CI −4.2 to 10.8. The estimate didn’t move; the honest n did. n counts the independent things you sampled: 8 cores, not 80 plugs.

5. Normality

Slide

  • exp(x) (new): e to the power x, the reverse of log(). Used here to make skewed, permeability-like data.
  • qqnorm(x) and qqline(x) (new): plot the data against what a normal sample of the same size would give, and add the line the points would follow if the data were normal.
  • shapiro.test(x) (new): the Shapiro–Wilk test. Its null is “these data are normal”, so a small p means not normal.
  • Already met: t.test(), log(), [ ], ==.
NoteHint 1
  1. t.test() mD by sandstone.
  2. Pull out sandstone B’s values; QQ-plot them and run shapiro.test(). (Then try A.)
  3. A new column, the log() of mD. Check it the same way, then t.test() the logs.
NoteHint 2 
t.test(<mD by sandstone>, data = perm)

b <- perm$mD[<sandstone is B>]
qqnorm(b)
qqline(b)
shapiro.test(b)

perm$log_mD <- log(perm$mD)
<the same three checks, on log(b)>
t.test(<log_mD by sandstone>, data = perm)

TipSolution 
t.test(mD ~ sandstone, data = perm)

b <- perm$mD[perm$sandstone == "B"]
qqnorm(b)
qqline(b)
shapiro.test(b)

perm$log_mD <- log(perm$mD)
qqnorm(log(b))
qqline(log(b))
shapiro.test(log(b))
t.test(log_mD ~ sandstone, data = perm)

On the raw values, p = 0.34: “no difference”, though we built a threefold one in. B’s QQ points bend up at the top: a long right tail (one plug at 1324 mD). Shapiro–Wilk agrees: p = 0.0001. Logged, the points sit on the line (p = 0.64), and the t-test on logs gives p = 0.006. Back on the original scale, exp() of the difference in log means: B is about 4 times as permeable as A (95 % CI 1.6 to 11). A skewed tail can hide a real difference, as well as invent one.

6. Equal variance

Slide

  • t.test(…, var.equal = TRUE) (new argument): Student’s t-test, which pools the two groups’ spreads into one. Leave it out and R runs Welch’s test, which keeps them apart.
  • Already met: ggplot(), aes(), geom_point(), tapply() (Week 5), sd().
NoteHint 1
  1. t.test() temp_c by area, adding var.equal = TRUE.
  2. Look first: the points for each area. Then one standard deviation per area: Week 5’s shortcut.
  3. The same t.test(), without var.equal.
NoteHint 2 
t.test(temp_c ~ area, data = wells, var.equal = ______)

ggplot(wells, aes(x = ______, y = ______)) +
  geom_point()
tapply(wells$temp_c, wells$______, ______)

t.test(temp_c ~ area, data = wells)
TipSolution 
t.test(temp_c ~ area, data = wells, var.equal = TRUE)

ggplot(wells, aes(x = area, y = temp_c)) +
  geom_point()
tapply(wells$temp_c, wells$area, sd)

t.test(temp_c ~ area, data = wells)

Student’s test: p = 0.006, the fell 2.3 °C warmer (95 % CI 0.7 to 3.8 °C). But the SDs are 4.1 °C on the fell and 0.8 °C in the lowland: a ratio of 5, where above about 2 is worth worrying about. Welch’s test: p = 0.23, df = 5.1, CI −2.0 to 6.5 °C. Same gap, honest uncertainty. R uses Welch’s test unless you tell it not to: leave it that way.
