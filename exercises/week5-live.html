Week 5: Live code

Wind farms and birds: finding a confounder

The live coding from Week 5: Designing your investigation, to reproduce at home. Do wind farm squares have fewer bird species, or does something else explain the gap?

squares holds every 10 km square of Great Britain: its bird species (2006–15), the number of records behind them, its land_fraction, and the largest wind farm (in turbines) built there by 2015 or later.

1. Do wind farm squares have fewer species?

Slide

  • ifelse(test, yes, no) (new): takes a vector of TRUE/FALSE and turns it into labels: yes where TRUE, no where FALSE.
  • stat_summary() (new): a ggplot layer that takes the points in each group and draws one summary instead. With fun.data = mean_se, fun.args = list(mult = 1.96) that is the mean, with a bar 1.96 standard errors either side: a 95 % confidence interval.
  • Already met: read.csv(), [ , ], >=, ggplot(), aes().
NoteHint 1
  1. A land square is one that is at least two-thirds land (land_fraction). Keep only those rows.
  2. A new column, farm: TRUE if largest_farm_by_2015 is 8 or more.
  3. Put farm on the x axis and species on the y axis, and summarize each group with stat_summary().
NoteHint 2 
squares <- squares[<which rows?>, ]
squares$farm <- <a TRUE/FALSE test>
ggplot(squares, aes(x = <group>, y = <outcome>)) +
  stat_summary(<mean and 95 % CI>)
NoteHint 3 
squares <- squares[squares$______ >= 2 / 3, ]
squares$farm <- squares$______ >= 8
ggplot(squares, aes(x = ______, y = ______)) +
  stat_summary(fun.data = ______, fun.args = list(mult = 1.96))
TipSolution 
squares <- squares[squares$land_fraction >= 2 / 3, ]
squares$farm <- squares$largest_farm_by_2015 >= 8
ggplot(squares, aes(x = farm, y = species)) +
  stat_summary(fun.data = mean_se, fun.args = list(mult = 1.96))

Then hone it: FALSE and TRUE make poor axis labels.

squares$farm <- ifelse(squares$largest_farm_by_2015 >= 8,
                       "Wind farm", "None")

No wind farm: 134.5 species (2100 squares). Wind farm: 126.3 (139 squares). About 8 fewer, and the intervals don’t overlap. Turbines harm birds? Before you agree: where do birdwatchers live?

2. A possible confounder: the outcome

Slide

  • cor(x, y) (new): takes two columns of numbers and gives one number, from −1 to 1: how closely they rise and fall together. method = "spearman" uses their ranks, so it doesn’t need a straight line.
  • sample(x) (new): takes a vector and returns the same values in a random order: a shuffle.
  • replicate(n, code) (new): runs the same code n times and collects the n answers into one vector.
  • quantile(x, probs) (new): takes numbers and gives the values that the fractions probs of them lie below. quantile(x, 0.95) is the value 95 % of x lies below.
  • Already met: ggplot(), aes(), geom_point().
NoteHint 1
  1. Correlate the records column with the species column.
  2. A scatter plot of species against records.
  3. The same correlation, with method = "spearman".
  4. Shuffle species with sample() and correlate again: that is a world where records and species are unrelated. replicate() does it 1000 times; quantile() says how far those chance correlations reach.
NoteHint 2 
cor(<x>, <y>)
ggplot(squares, aes(x = <x>, y = <y>)) + geom_point()
cor(<x>, <y>, method = "spearman")
nulls <- replicate(1000, cor(<x>, sample(<y>)))
quantile(nulls, c(0.05, 0.95))
NoteHint 3 
cor(squares$______, squares$______)
ggplot(squares, aes(x = records, y = species)) + geom_point()
cor(squares$records, squares$species, method = "______")
nulls <- replicate(1000, cor(squares$records, ______(squares$species)))
quantile(nulls, c(0.05, 0.95))
TipSolution 
cor(squares$records, squares$species)
ggplot(squares, aes(x = records, y = species)) + geom_point()
cor(squares$records, squares$species, method = "spearman")

nulls <- replicate(1000, cor(squares$records, sample(squares$species)))
quantile(nulls, c(0.05, 0.95))

Pearson’s correlation is 0.71. The scatter curves: species climb fast, then level off, so a straight-line measure undersells it. Spearman’s, which needs only “more goes with more”, is 0.82.

Is that a big number? Shuffled, 90 % of the correlations fall within about ±0.03. Squares with more records list more species.

3. A possible confounder: the exposure

Slide

  • geom_violin() (new): draws each group’s values as a mirrored outline: fat where values are common, thin where they are rare.
  • tapply(x, group, f) (new): splits x by group and applies the function f to each piece, so tapply(x, group, median) gives one median per group. (In Python: groupby().agg().)
  • scale_y_log10() (new, optional): puts the y axis on a log scale, so 1000, 10 000 and 100 000 sit equally far apart.
  • Already met: ggplot(), aes(), median(), [ ], ==.
NoteHint 1
  • Look: records for each value of farm, as violins.
  • The long way: the median of records, keeping only the rows where farm is "None"; then again for "Wind farm".
  • The shortcut: tapply() does both at once.
NoteHint 2 
ggplot(squares, aes(x = <group>, y = <outcome>)) + geom_violin()
median(<records>[<farm is "None">])
median(<records>[<farm is "Wind farm">])
tapply(<what>, <split by>, <function>)
NoteHint 3 
ggplot(squares, aes(x = farm, y = ______)) + geom_violin()
median(squares$records[squares$farm == "______"])
median(squares$records[squares$farm == "______"])
tapply(squares$records, squares$______, median)
TipSolution 
ggplot(squares, aes(x = farm, y = records)) + geom_violin()
median(squares$records[squares$farm == "None"])
median(squares$records[squares$farm == "Wind farm"])

# the shortcut
tapply(squares$records, squares$farm, median)

The violins are squashed flat by a few city squares with hundreds of thousands of records; add + scale_y_log10() to see their shapes. That skew is also why we use the median, not the mean.

Median records: 5130 in wind farm squares, 11 456 in the rest. Wind farm squares are looked at half as hard. Recording effort is tied to both the outcome (box 2) and the exposure: a confounder.

4. Allowing for recording effort: stratification

Slide

  • cut(x, breaks) (new): takes numbers and sorts each into a band, given the band edges. include.lowest = TRUE keeps the smallest value, which sits exactly on the bottom edge; dig.lab = 6 prints the edges in full.
  • table(x) (new): counts how many times each value appears.
  • ave(x, group) (new): tapply()’s cousin. It gives each row the average of its group, so the answer lines up with x, row for row.
  • Already met: quantile(), summary(), 0:10.
NoteHint 1
  1. Ten equal bands need eleven edges: the 0 %, 10 %, …, 100 % points of records. 0:10 / 10 gives those fractions; quantile() turns them into numbers of records; cut() puts each square in its band. Store the band in a new column, then count the squares in each.
  2. A new column: species minus the band average.
NoteHint 2

Look at four edges first: summary(squares$records) gives the quartiles. Ten bands work the same way.

squares$band <- cut(<records>, <eleven edges>,
                    dig.lab = 6, include.lowest = TRUE)
table(squares$band)
squares$vs_band <- <species> - ave(<species>, <band>)
NoteHint 3 
squares$band <- cut(
  squares$records,
  quantile(squares$records, ______),
  dig.lab = 6,
  include.lowest = TRUE
)
table(squares$band)
squares$vs_band <- squares$species - ave(squares$______, squares$______)
TipSolution 
squares$band <- cut(
  squares$records,
  quantile(squares$records, 0:10 / 10),
  dig.lab = 6,           # legibility
  include.lowest = TRUE  # bottommost square
)
table(squares$band)

squares$vs_band <- squares$species -
  ave(squares$species, squares$band)

About 224 squares in each band, from 158–1176 records up to 52 207–311 015. A square with ten thousand garden-feeder records will list more species than a moor that three people visited; now each is compared only with squares looked at about as hard.

5. Allowing for recording effort: the result

Slide

  • Already met: ggplot(), aes(), stat_summary().
NoteHint 1

Copy your plot from box 1 and change one thing: the outcome on the y axis is now vs_band.

NoteHint 2 
ggplot(squares, aes(x = farm, y = ______)) +
  stat_summary(fun.data = mean_se, fun.args = list(mult = 1.96))
TipSolution 
ggplot(squares, aes(x = farm, y = vs_band)) +
  stat_summary(fun.data = mean_se, fun.args = list(mult = 1.96))

No wind farm: −0.3 species against the band (95 % CI −1.3 to 0.7). Wind farm: +4.5 (1.1 to 7.9). The answer has reversed: turbines help birds? A wind farm developer would print this one. Are we reading the correlation the right way round?

6. Identifying causality

Slide

  • ! (new): turns TRUE into FALSE and FALSE into TRUE. squares[!squares$any_wind_by_2015, ] keeps the rows where any_wind_by_2015 is FALSE.
  • Already met: ifelse(), ggplot(), aes(), stat_summary().
NoteHint 1
  1. any_wind_by_2015 is TRUE for squares with any turbine by 2015. Keep the others, in a new data frame, untouched.
  2. A new column, later, built like farm in box 1, from largest_farm_later.
  3. Box 5’s plot, with untouched and later.
NoteHint 2 
untouched <- squares[<not any_wind_by_2015>, ]
untouched$later <- ifelse(<8 or more turbines later>,
                          "Wind farm later", "Never")
ggplot(untouched, aes(x = <group>, y = vs_band)) +
  stat_summary(fun.data = mean_se, fun.args = list(mult = 1.96))
NoteHint 3 
untouched <- squares[______squares$any_wind_by_2015, ]
untouched$later <- ifelse(untouched$______ >= 8,
                          "Wind farm later", "Never")
ggplot(untouched, aes(x = ______, y = vs_band)) +
  stat_summary(fun.data = mean_se, fun.args = list(mult = 1.96))
TipSolution 
untouched <- squares[!squares$any_wind_by_2015, ]
untouched$later <- ifelse(untouched$largest_farm_later >= 8,
                          "Wind farm later", "Never")
ggplot(untouched, aes(x = later, y = vs_band)) +
  stat_summary(fun.data = mean_se, fun.args = list(mult = 1.96))

Never: −1.4 (−2.5 to −0.3; 1711 squares). Wind farm later: +3.7 (1.2 to 6.2; 238 squares). A gap of about +5, before any turbine was built. Turbines can’t have caused it: developers choose sites that were already better for birds. “Later” includes refused applications; they still show where developers chose to go.
