1. HolmesCo’s latest results

Slide

HolmesCo sampled iron upstream and downstream of every site treated with its FerroGone, and of ten sites treated with a competitor’s ClearFlow. FerroGone: “significant difference, p = 0.03”. ClearFlow: “no significant difference, p = 0.07”. Check their claims.

  • t.test(x, y, paired = TRUE) (new): pairs each downstream reading with the upstream reading from the same site, and tests whether the differences, x − y, average zero.
  • alternative = "less" (new): one-tailed. Counts only differences below zero, i.e. iron falling. The default, "two.sided", counts both directions.
  • Already met: read.csv(), head(), [ , ] with a condition (Week 1).
NoteHint 1
  1. head() shows the columns: product, upstream_mg_l, downstream_mg_l.
  2. Keep the FerroGone rows, then t.test() the downstream readings against the upstream ones, paired by site.
  3. The same for ClearFlow.
  4. The output’s “mean difference” is downstream − upstream. Positive means more iron after treatment.
  5. Repeat both tests with alternative = "less".

FerroGone: mean difference +0.75 mg/L, p = 0.032. HolmesCo quoted it correctly, but the significant difference is iron going up. Asked the question that matters, “does it lower iron?”, FerroGone gets p = 0.98.

ClearFlow: −0.47 mg/L, p = 0.069 two-tailed, but 0.034 one-tailed. Ten sites were too few to see a fall that size in both directions at once: if the true fall is 0.47 mg/L, ten sites catch it two-tailed less than half the time; about 21 would catch it four times in five.

The tail belongs to the question, so choose it before you sample. These data are simulated.

2. Chance in action

Slide

  • t.test(x, y) (new use): two vectors of numbers, in place of a formula and a data frame.
  • $p.value (new): takes just the p-value out of a test’s result.
  • Already met: rnorm() (Week 6), replicate(), set.seed(), sum(), mean(), table() (Weeks 5–6).
NoteHint 1
  1. rnorm(25) twice: both from the same normal distribution. Keep the p-value of their t-test. Run it a few times.
  2. replicate() step 1 20 times, then count the p-values below 0.05. Run that a few times too.
  3. set.seed(7), then replicate() step 2 1000 times. What fraction of surveys found at least one? table() shows how many found 0, 1, 2, ….

The p-values bounce around, and some surveys turn up a “discovery”. Over 1000 surveys, 67 % find at least one; 76 (about 1 in 13) find three or more. The shortcut, as t.test() was for the shuffle: 1 − 0.95²⁰ ≈ 0.64. The difference is simulation noise.

3. The null world for F

Slide

  • aov(outcome ~ group) (new): fits an analysis of variance. summary() of it gives a table whose "F value" column holds F.
  • summary(aov(…))[[1]][["F value"]][1]: digs F out of that table: the first table, its "F value" column, its first row.
  • function(region) { … }: met in Week 3. Here it saves typing the line above for every shuffle.
  • Already met: read.csv(), sample(), set.seed(), replicate(), ggplot(), geom_histogram(), geom_vline(), mean().
NoteHint 1

Week 6’s shuffle, line for line, with F where δ was.

  1. Read data/wind_output.csv into wind. Write a function, f_of, that takes region labels and returns F for capacity_pct explained by them. f_obs is F for the real labels.
  2. f_of() of shuffled labels. Run it a few times.
  3. set.seed(7), then 1000 of those.
  4. A histogram, with f_obs marked. Then the fraction of shuffles with an F at least as big. One tail only: F can’t be negative.

wind <- read.csv("data/wind_output.csv")
f_of <- function(region) {
  summary(aov(wind$capacity_pct ~ region))[[1]][["F value"]][1]
}
f_obs <- f_of(wind$region)
f_obs

f_of(sample(wind$region))

set.seed(7)
null_f <- replicate(1000, f_of(sample(wind$region)))

ggplot(data.frame(null_f), aes(x = null_f)) +
  geom_histogram(bins = 30) +
  geom_vline(xintercept = f_obs, colour = "red")

mean(null_f >= f_obs)

F = 14.21. Shuffled F values huddle near 1; the largest of 1000 is 8.8. None reaches 14.2, so the simulated p is below 1/1000. The shortcut, summary(aov(capacity_pct ~ region, data = wind)), gives F(3, 96) = 14.21, p = 9.8 × 10⁻⁸. This is an ANOVA, just as Week 6’s shuffle was a t-test.
