One tail or two?

11:18

w08-tails.R

  • [11:18–11:26] A refresher on Week 6 as much as a new idea. The null world: shuffle the formation labels, recompute δ, 1000 times; the p-value is the share of shuffles as extreme as ours.
  • “As extreme” in which direction? Two-tailed: either (22 of 1000, p = 0.022). One-tailed, “is Stainmore warmer?”: only the upper tail (13 of 1000, p = 0.013). Same null world, about half the p-value.
  • t.test() does the same: two-sided p = 0.030; alternative = "greater" gives 0.015, exactly half.

  • Numbers (10 sites each, simulated): FerroGone mean difference +0.75 mg/L, p = 0.032. ClearFlow −0.47 mg/L, p = 0.069.

  • Twist 1: FerroGone’s “significant difference” is iron going up. Don’t buy it. HolmesCo asked “any difference?” when the only question that matters is “does it lower iron?”: one-tailed, alternative = "less" (downstream − upstream < 0). FerroGone, one-tailed: p = 0.98.

  • Yes, we picked the tail after seeing the data. That is the next slide’s warning: the question was one-tailed from the start, and should have been written down before anyone sampled.

  • paired = TRUE is a one-sample t-test on the differences, the constrained shuffle from Week 6’s “What would the null world be?”

Mine water: only better counts

11:23

Pool stained with iron, Blast Beach, Seaham: Andrew Curtis / Geograph, CC BY-SA 2.0

Has iron fallen?

  • If it doesn’t cut iron, it doesn’t work: if it increases iron I’m definitely not paying for it!

When only one direction is interesting: use a one-tailed test.

Define your question before you ask it.

A one-tailed test after a two-tailed test fails is a second test: and a second chance to see a false positive.

  • In R: t.test(iron ~ period, data = water, alternative = "less"). The alternative is about the first group minus the second, in alphabetical order: “after” − “before”, so “less” means iron fell. Check which way round R took it.
  • A one-tailed test can’t see an effect the other way. If an increase would matter (would we close the scheme, or sue?), test both tails.
  • The key point leads into the next section: doubling the chances of a false positive is the multiple comparisons problem in miniature.

Is your coin fair?

11:28

Black hole and accretion disk: BoliviaInteligente / Unsplash, Unsplash Licence

w08-coin-null.R

If all six came out the same: your coin is biased, p < 0.05.

  • The null world again, but exact this time: dbinom() gives each bar, no shuffling needed. All heads or all tails has probability 2 / 64 = 0.031; adding five-of-one would take it to 0.22, far too big for p < 0.05.
  • Count the hands. Expect about 2 in a room of 70 (70 × 0.031 ≈ 2.2); 89 % of the time at least one hand goes up. If none does, the next slide still holds: we expected two.
  • Optional: ask a “biased” student to toss six more. Odds are 31 to 1 that they won’t repeat it.

Expecting false positives

11:31

Each of you just tested a hypothesis on a fair coin.

Null hypothesis: Coin is fair

Null hypothesis is rejected (p = 0.031) if all flips landed the same

~70 tests × 0.031: we expected about 2 false positives.

Run enough tests and some will be “significant”, even when nothing is going on.

  • Ask the “biased” students: would you publish? Each test was done correctly; the problem is how many we ran.

The answer

11:36

20 × 20 = 400 tests at p = 0.05

Expected false positives: 20, about one per site.

In the null world (no elements enriched), there’s a ~4 in 5 chance that three samples will test as “enriched” in at least one site.

  • Each site’s hits are binomial(20, 0.05): one site reaches three with probability 0.075; across 20 sites, 1 − 0.925²⁰ ≈ 0.79.
  • So one site in 13 scores three or more by chance alone. With 20 sites, one of them doing so is the expected outcome.
  • Keep this survey in mind: Bonferroni comes back to it.

Compared to what?

11:43

w08-wales-seng.R

Welsh sites average δ = 1.4 percentage points more capacity factor.

Divide δ by Gives Answers
null world: SE = 1.2 t = 1.2 How sure?
spread of sites: SD = 4.3 d = 0.33 How big?

More sites shrink the SE, not the SD.

  • [11:43–11:49] Week 6’s δ, judged two ways. Both are “Is that a big number? Compared to what?”
  • d (Cohen’s d) compares the gap with how much sites vary: how many site-to-site SDs apart are the means? t compares it with how much the mean would wobble in the null world.
  • From wind_output.csv, 25 sites per region: δ = 1.43, pooled SD = 4.35, SE = 4.35 × √(2/25) = 1.23, t = 1.17, p = 0.25, d = 0.33.
  • Pooled SD: √((4.37² + 4.33²) / 2). The exercise page (application session) computes d by hand for Scotland vs Southern England: 1.54.
  • With two groups of n, SE = SD × √(2/n): four times the sites halves the SE.

Taking more measurements:

11:49

With the same means and spread, as you measure more sites per region, the same size difference becomes less likely by chance

Sites per region SE t p d
25 1.23 1.2 0.25 0.33
100 0.61 2.3 0.02 0.33
400 0.31 4.7 < 0.001 0.33

Significance asks: Do you have enough data to detect a difference this small?

d asks: Is the difference big, relative to other variation?

  • [11:49–11:52] The Week 6 refrain, in numbers: “significant ≠ important”.
  • Hypothetical rows: δ = 1.43 and SD = 4.35 held fixed, SE = SD × √(2/n), p from the t distribution with 2n − 2 df.
  • Ask: at 400 sites a region, would a developer now pick Wales over Southern England? The difference is no bigger than it was at 25.
  • Whether 1.4 points matters is a question about turbine economics, not statistics. d puts it on a common scale; it doesn’t decide.

From δ to F

11:54

Compare two groups and get one δ

(δ = the difference between the means).

Compare four groups and get six δs… 🤔

One number instead:

\[F = \frac{\text{spread between means}}{\text{spread between sites within a group}}\]

t asks “Is this δ noteworthy”?

F asks “Are these δs, taken together, noteworthy?”

  • [11:54–12:03] From δ to F, “Relative to within”, then aov() typed live.
  • δ was “how far apart are the means?”, judged against the null world’s spread. F asks the same of four means at once: how spread out are they, compared with the noise inside each group?
  • The bottom line is the same yardstick δ used. In Week 6 we judged δ against the spread of the null world (the SE), which came from the scatter of the boreholes.
  • With exactly two groups, F = t²: same test (Exercise 2’s extension has students check this).
  • Like t, F grows with the number of sites, so a big F says “sure”, not “big”.

Option 1: Tukey’s HSD

12:16

When: after an ANOVA, to compare every pair of groups.

  • [12:16–12:28] Tukey, then Bonferroni, then which to use.

  • Anticipated code:

    tukey_result <- TukeyHSD(wind_aov)
tukey_result

  • TukeyHSD() takes the fit, not its summary. The hidden setup refits wind_aov, so the box runs even if the last slide was skipped.

  • p adj is already corrected for the six pairs: compare it with 0.05 as it stands.

  • Numbers from a real run, on my data: one pair of six, Southern England vs Northern England, p adj = 0.049. Scotland vs Southern England just misses (0.068).

  • Students repeat this on the real sites in Exercise 3, and find four pairs. Don’t give that away.

  • HSD: “honestly significant difference”.

Option 2: Bonferroni

12:20

The generalized (if slightly ad hoc) alternative, for any set of tests.

How: with k tests, each one needs p < 0.05 / k.

HolmesCo’s survey: 400 tests, so each needs p < 0.05 / 400 = 0.000125.

Not ideal: just raises the bar by a fixed fraction. With many tests, the bar gets high!

  • Equivalently, multiply each p by k and compare with 0.05. That is what R’s p.adjust(p, "bonferroni") reports.
  • On the wind data, pairwise.t.test(wind$capacity_pct, wind$region, p.adjust.method = "bonferroni") picks out the same four pairs as Tukey. Exercise 3’s extension compares the two.
  • The cost: with many tests the bar is so high that real effects get missed. Better to decide in advance which few comparisons matter.

Tukey or Bonferroni?

12:24
Tukey’s HSD Bonferroni
Use it for Every pair of groups, after an ANOVA Any set of k tests
Each test needs p adj < 0.05 p < 0.05 / k

Both raise the bar for each test, so the whole family keeps its 5 % chance of a (single) false positive.

  • Don’t go deep into the maths. Tukey is a little less strict for all-pairs comparisons, because it allows for the pairs sharing groups.

For ANOVA: η² (eta-squared)

12:34

t-test: d. Linear model: R². ANOVA: η², the share of the variation explained by the groups.

\[\eta^2 = \frac{\texttt{Sum Sq}\ \texttt{region}}{\texttt{Sum Sq}\ \texttt{region} + \texttt{Sum Sq}\ \texttt{Residuals}}\]

Mine: 857.6 / (857.6 + 7724.4) = 0.10

η² Interpretation
0.01 Small
0.06 Medium
0.14 Large

Always report both the p-value and an effect size.

“Is it real?” → “how big?” (→ “do I care?”)

  • [12:34–12:39] Back to “Is that a big difference?”: d says how big for two groups, η² for several. Neither grows with n.
  • Mine: 857.6 / 8582.0 = 0.10, medium. Same differences as the real sites, four times the scatter, so the groups explain less. Students get 0.31 on the real sites on the application page: don’t give it away.
  • aov() is lm() with a categorical predictor: summary(lm(capacity_pct ~ region)) gives R² = η², the same number.
  • Link to “Is that a big number?” from Week 2. Same habit, formalized.
